5.1 — The Form Element & Text-Type Inputs

The <form> element and labels

Live demo

Click the label text — the cursor jumps into the box. That’s the for/id connection working, and it’s what screen readers announce.

<form action="#" method="get">
  <label for="name">Full Name:</label>
  <input type="text" id="name"
         name="name" required>
  <button type="submit">Submit</button>
</form>

Email, telephone, URL, password, number

Live demo

Try “abc” in Email or Website. On a phone, the keyboard changes for email, tel, and number.

<label for="email">Email Address:</label>
<input type="email" id="email"
       name="email" required>

<label for="phone">Phone:</label>
<input type="tel" id="phone" name="phone">

<label for="site">Website:</label>
<input type="url" id="site" name="site">

<label for="pwd">Password:</label>
<input type="password" id="pwd"
       name="pwd" minlength="8" required>

<label for="age">Age (1-120):</label>
<input type="number" id="age" name="age"
       min="1" max="120">

Validation attributes: required, minlength, maxlength, pattern

Live demo

No JavaScript anywhere on this page — the browser does all of this checking for free.

<input type="text" id="nick" name="nick"
       minlength="3" maxlength="10" required>

<input type="text" id="code" name="code"
       pattern="[A-Za-z]{3}"
       title="Enter exactly three letters">

5.2 — Radio Buttons, Checkboxes & Dropdowns

Radio buttons (pick one)

Live demo

Preferred contact method

Every radio in the group shares the same name, so only one can be selected. Each has its own id and value.

<fieldset>
  <legend>Preferred contact method</legend>
  <input type="radio" id="contact-email"
         name="contact" value="email">
  <label for="contact-email">Email</label>

  <input type="radio" id="contact-phone"
         name="contact" value="phone">
  <label for="contact-phone">Phone</label>

  <input type="radio" id="contact-text"
         name="contact" value="text">
  <label for="contact-text">Text Message</label>
</fieldset>

Checkboxes (pick any)

Live demo

Skills you want to learn

HTML is pre-checked with the checked attribute. Use that sparingly — don’t pre-select something the user may not want.

<fieldset>
  <legend>Skills you want to learn</legend>
  <input type="checkbox" id="cb-html"
         name="skills" value="html" checked>
  <label for="cb-html">HTML</label>

  <input type="checkbox" id="cb-css"
         name="skills" value="css">
  <label for="cb-css">CSS</label>

  <input type="checkbox" id="cb-js"
         name="skills" value="js">
  <label for="cb-js">JavaScript</label>
</fieldset>

5.3 — Textarea & Submit Buttons

Textarea (multi-line text)

Live demo

Textarea is not self-closing — it needs both <textarea> and </textarea>.

<label for="message">Your Message:</label>
<textarea id="message" name="message"
          rows="4" cols="30"
          maxlength="300"
          placeholder="Type your message here...">
</textarea>

Submit and reset: <button> vs. <input>

Live demo

Preferred: <button>

Also valid: <input type="submit">

<button> can hold HTML (like an icon); <input type="submit"> can only show plain text. Always state the type explicitly.

<!-- Preferred -->
<button type="submit">Send Message</button>

<!-- Resets every field in the form -->
<button type="reset">Clear All</button>

<!-- Also valid, plain text only -->
<input type="submit" value="Send Message">

Putting It Together: A Complete Accessible Form

This is the pattern you’ll use for Checkpoint 2: at least three input types, a visible label on every input, fieldset + legend around radio and checkbox groups, and HTML5 validation attributes.

Tours (choose any) 
<form action="#" method="get">
  <label for="f-name">Full Name</label>
  <input type="text" id="f-name"
         name="f-name" required>

  <label for="f-email">Email Address</label>
  <input type="email" id="f-email"
         name="f-email" required>

  <fieldset>
    <legend>Ticket Type</legend>
    <!-- radios sharing name="ticket" -->
  </fieldset>

  <fieldset>
    <legend>Tours (choose any)</legend>
    <!-- checkboxes -->
  </fieldset>

  <label for="f-state">Home State</label>
  <select id="f-state" name="f-state">...</select>

  <label for="f-notes">Comments</label>
  <textarea id="f-notes" name="f-notes"
            rows="3"></textarea>

  <button type="submit">Register</button>
  <button type="reset">Clear</button>
</form>
